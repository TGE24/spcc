# Church Website

Built from `church_website_prd.md` and `church_website_technical_spec.md`.

**Stack:** Next.js (App Router) + Supabase (database, auth, storage).

## Getting started

See [SETUP.md](./SETUP.md) for the full walkthrough (creating a Supabase
project, configuring environment variables, running the database migrations,
and creating your first admin account).

Once set up:

```bash
npm run dev
```
